# Changelog

All notable changes to **MailPilot AI** will be documented in this file.

## [1.0.0] - 2026-07-28

### Added
- **React 19 + TypeScript + Vite Frontend**: Linear/Vercel modern dark & light UI design system.
- **FastAPI + Python 3.13 Backend**: Modular architecture with SQLAlchemy 2.0 ORM (SQLite / PostgreSQL ready).
- **Gmail OAuth2 & Zero-Config Mock Engine**: Allows instant zero-setup demo testing out of the box.
- **20 Smart Email Categories**: NLP & heuristic categorizer (Finance, Work, OTP, Security, Receipts, Subscriptions, GitHub, etc.).
- **Newsletter Subscription Manager**: 1-click unsubscribe and recurring volume tracking.
- **Phishing & Spam Guard**: Real-time spoofing & credential harvesting detection.
- **Custom Automation Rules Builder**: Unlimited dynamic rules (archive, star, label, auto-delete OTPs > 30 days).
- **Attachment Vault & Storage Analyzer**: Content type filtering & file size breakdown.
- **Command Palette (`Cmd+K`)**: Keyboard shortcuts for instant navigation and actions.
- **Plugin Architecture**: Foundation for Microsoft Outlook, Yahoo, IMAP, and Proton Mail extensions.
- **DevOps & GitHub Setup**: Dockerfile, docker-compose, DevContainer, GitHub Actions CI/CD, CodeQL, Dependabot.
